Wired-Up Demo

Reader, reasoner, calculator, notebook and sleep loop running together on a laptop CPU.

Plumbing only. The language model here is a tiny stand-in, the data is toy data written for the tests, and nothing is an evaluation. This shows the parts connect. It does not show that Premonition reads, reasons or learns.

The parts, connected

Orange dashed boxes are stand-ins or frozen. Blue boxes are trained. Everything is about 1.7M parameters, of which 1.2M train.

One episode

The core never writes free text for a calculation. It picks a small structured action, the host carries it out, and the result goes back in as new rows the core can read.

The notebook pair test, in plumbing form

Same question word for word. Only one notebook fact differs, so the correct number to pick differs. A model that ignores the notebook can get at most one of the two right.

The notebook never supplies a number. It decides which number in the question to use, which matches the real pipeline's rule that calculator operands must come from the question.

What the tests showed

16 CPU tests pass, in about two minutes. They also ran on your Mac in a fresh copy of the branch.

Weak spot. The model-driven notebook write only half works: on training steps the write action is right 6 of 16 times in the plain run. The write helper itself is tested and fine; the model has not learned when to use it. The same model also needs more than 600 updates before it uses the notebook at all (0 of 8 pairs at 600).

What this does not show

  • Nothing about the real 1.2B model, its tokenizer, or number handling.
  • Overfitting 48 toy problems says nothing about new questions. Passing the pair test on training pairs says the notebook reaches the pointer heads, not that the model can read a new fact.
  • The answer value comes from a pointer. The real open problem, getting a number through the 8 prefix vectors into model text, is not tested.
  • Sleep records are checked against the generator's answer key, which is the weakest kind of check. No retention or learning claim.
  • Real core is a mixture of experts and refuses padding. Here it is dense and padded with a mask.
