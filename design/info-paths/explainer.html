Getting more information into the model

Attention is fine. The two doors are too narrow.

Inside, the thinking core passes information around well. It gets lost at the way in and the way out.

Does the talker need to read the question? 6 seeds, 5:25 PM ETyes, it does

Without the question's words the talker gets 19%; with them, 83%

Three talkers, same training. Today's sees the core's 16 vectors, then every question word. "Question first" puts the words before the vectors so the second read can reuse the first. "Core vectors only" sees no words at all.

All three take the same time, about 3x the bare model to the first word and 1.3x for an 8-word answer. So re-reading the question isn't what costs time. The cost is the core plus one extra pass, which costs about the same at any length (inferred). Question first loses 8 points and saves nothing.

Read: keep today's talker. A talker that only translates the core's state would need a much stronger copy path than the 8-slot pointer. Cost about $2.30, including a pause for credit.
