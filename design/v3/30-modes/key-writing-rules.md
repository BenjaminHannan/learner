# Answer-key writing rules (director rulings, 2026-09-23)

These apply to every gold key and blind panel written from now on. Older sealed panels keep their own keys.

1. **Negatives.** "X doesn't have a dog" / "X has no dog" saves nothing. Gold: no TEACH frame, and never a "dog: none" value. The key marks the turn `negation`. Whether an existing entry gets deleted is the forget/deny path's job (262-style), not the ear's; panels that test that must say so in their own spec.
2. **"so X is Y" with no question mark** is a check, not a teach. Gold: an ASK (confirm) frame, no TEACH. The same goes for "so X is Y right" and "X is Y, yeah". A plain statement with no "so"/"right"/"yeah" is still a teach.
3. **Muse-written keys need an audit.** A key or panel written by a Muse builder must pass a blind Opus audit (a separate labeller relabels a sample without seeing the key; any disagreement is resolved before the key is used for grading) before it can grade a registered run.
4. Earlier rulings still stand: a narrower relation counts as a hit (Ruling 1, 261b-decision.md). "our/we/us" facts get an ask-whose (265-our-ask.md). A plural "A and B are my sisters" frame that names either true name is correct.
