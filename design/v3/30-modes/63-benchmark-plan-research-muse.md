# 63 — Benchmark plan (research scout, 2026-09-21)

What we can already do (local evidence): notebook answers 20/20 two-hop over 120 taught facts and 5/5 newly taught facts after training, baseline transformer 0/20 and 0/5 (`artifacts/fable-demo55-20260921/RESULTS.md`); reasoner matches the notebook contract field-for-field on 2,700 frames incl. all five statuses, 90/90 MISSING_FACT on unknown relations, 0 wrong of 540 sleep audits (`artifacts/fable-reasoner50-20260921/RESULTS.md`); wired loop holds 6/6 two-hop with 0 wrong writes and 3/3 abstentions (`artifacts/fable-wire51-20260921/RESULTS.md`). This doc maps those four abilities onto public benchmarks an expert accepts.

## 1. Benchmark catalogue (paper numbers labelled [P]; my estimates [E])

**MQuAKE** (multi-hop editing: 2/3/4-hop). https://github.com/princeton-nlp/MQuAKE ; paper https://arxiv.org/abs/2305.14795 . Licence MIT [P, repo page]. Size [P, paper Table 2]: MQuAKE-CF 9,218 instances (4,879 1-edit, 3,745 2-edit, 1,282 3-edit, 436 4-edit); MQuAKE-T 1,868 (paper) / 1,825 (repo README) — use repo count at run time. Format: JSON tuple ⟨edits E, 3 questions Q, answers a/a*, fact chains C/C*⟩; edits in CounterFact cloze style. Sentence ears must parse: "Who is married to the British Prime Minister?" after edit "The current British Prime Minister is Rishi Sunak." [P]. Key result [P]: editors recall single facts but "fail catastrophically" on multi-hop; memory-based MeLLo beats ROME/MEMIT by a large margin.

**MQuAKE-Remastered** (the version to actually run). https://huggingface.co/datasets/henryzhongsc/MQuAKE-Remastered ; code https://github.com/henryzhongsc/MQuAKE-Remastered ; paper ICLR 2025 https://proceedings.iclr.cc/paper_files/paper/2025/hash/f782860c2a5d8f675b0066522b8c2cf2-Abstract-Conference.html . Licence CC-BY-4.0 [P, HF card]. Size [P, HF README]: CF-3k (fixed subset), CF-9k (full, fixed), CF-6334 (train/test split for parameter editors), T (temporal). Format: parquet/JSON, same schema plus edit triples with Wikidata IDs. Finding [P]: 33–76% of original MQuAKE questions/labels corrupted (contamination, conflicts, duplicates); many prior methods overfit original idiosyncrasies; their simple GWalk baseline beats SOTA post-fix.

**RippleEdits.** https://github.com/edenbiran/RippleEdits ; paper https://arxiv.org/abs/2307.12976 . Licence MIT [P, repo page]. Size [P]: 5,000 edits in three files: RECENT / RANDOM / POPULAR. Format: JSON edit + ripple test queries (logical, compositional, subject-alias, preservation). Sentence: edit "Jack Depp is the son of Johnny Depp" ⇒ must update "Jack Depp is the sibling of Lily-Rose Depp" [P]. Result [P]: current editors fail ripple consistency; plain in-context baseline scores best.

**CounterFact.** Data https://rome.baulab.info/data/dsets (counterfact.json, 43 MB); paper Meng et al. 2022. Licence: not found. Size [P]: 21,919 counterfactual records, 20,391 subjects [P, via https://arxiv.org/pdf/2405.02765 ]. Format: JSON with requested rewrite, subject tokens (for ROME/MEMIT), paraphrases, neighbourhood (specificity), generation probes (consistency/fluency). Sentence: cloze "The Louvre is located in ___" with counterfactual target Rome [P]. Reference numbers [P]: 10k-edit GPT-J MEMIT score 85.8 (efficacy 98.9, paraphrase 88.6, locality 73.7) vs ROME 50.3 — from https://arxiv.org/html/2210.07229 .

**zsRE.** Zero-shot relation extraction QA (Levy et al. 2017), eval split `zsre_mend_eval.json` at same data URL above. Licence: not found. Size [P]: 244,173 train / 27,644 valid originally; editing papers use 10k subsets [P, via https://arxiv.org/pdf/2405.02765 ]. Format: JSON question + paraphrase + answer. Sentence: "In which country is [x]?" [P, via https://arxiv.org/html/2307.12976v2 ]. Reference [P]: 10k-edit GPT-J MEMIT efficacy 96.7 / paraphrase 89.7 / locality 26.6 (ROME collapses on locality 0.9) — https://arxiv.org/html/2210.07229 .

**Reversal Curse (Berglund et al.).** Code+data https://github.com/lukasberglund/reversal_curse ; paper https://arxiv.org/abs/2309.12288 (ICLR 2024). Licence: not found. Size [P]: Experiment 1 = 30 fictitious celebrity facts + paraphrases, NameIsDescription / DescriptionIsName splits; Experiment 2 = real-celebrity parent/child Q/A. Format: text docs + QA prompts. Sentence: train "Uriah Hawthorne is the composer of Abyssal Melodies" ⇒ test "Who composed Abyssal Melodies?" [P]. Results [P]: finetuned GPT-3/Llama-1 at chance on reverses; GPT-4 79% forward vs 33% reverse. Directly relevant: encoder-side follow-up finds BERT-110M immune on classification reformulation while GPT-3/Llama-3-8B fail — https://pmc.ncbi.nlm.nih.gov/articles/PMC11573886 .

**TwoHopFact / grokked-transformer two-hop sets.** https://huggingface.co/datasets/soheeyang/TwoHopFact ; paper https://arxiv.org/abs/2402.16837 . Licence CC-BY-4.0 [P, HF card]. Size [P]: 45,595 one-hop/two-hop prompt pairs, 52 fact-composition types over Wikidata. Format: CSV via Datasets. Sentence: "The mother of the singer of 'Superstition' is named ___" (bridge entity Stevie Wonder) [P]. Companion synthetic work (Wang et al. 2024, https://arxiv.org/html/2405.15071v3 ): 200 relations × 20 edges/entity random KG, grokking-only two-hop generalisation; their grokked small transformer hits 99.3% vs GPT-4-Turbo+RAG 33.3% on the synthetic test [P]. Real-world extension on 2WikiMultiHopQA claims 95–100% after augmentation [P, https://proceedings.mlr.press/v267/abramov25a.html ] — treat as unverified until reproduced.

**Abstention: SelfAware / AbstainQA / FreshQA / AbstentionBench.** SelfAware (Yin et al. 2023): unanswerable-known-unknown QA; size/licence: not found in this pass. AbstainQA (Feng et al. 2024, https://github.com/BunsenFeng/AbstainQA ): 2,900 zero-shot MCQA samples [P, via https://arxiv.org/html/2407.16221v1 ] with Answerable–Unanswerable confusion-matrix metric (Abstention Rate); licence not found. FreshQA (time-sensitive, answers change): question text + effective-date; size/licence not found in this pass. Umbrella to run: **AbstentionBench** (NeurIPS 2025 D&B, https://arxiv.org/abs/2506.09038 ; runner https://ukgovernmentbeis.github.io/inspect_evals/evals/abstention_bench/index.html ): 20 datasets (incl. FreshQA, SelfAware, SQuAD2, KUQ, FalseQA, SituatedQA), 369 MB download [P], abstention-recall vs correctness broken out by cause (unknown / underspecified / false-premise / stale / subjective).

**2025–2026 successors (verified to exist; details thinner).** **QAEdit** (ACL 2025, https://aclanthology.org/2025.acl-long.745 ): QA-aligned editing benchmark + WILD eval; headline [P]: prior methods drop 96.8% → 38.5% without teacher-forcing leakage. **AKEW** (EMNLP 2024, https://arxiv.org/abs/2402.18909 ): structured / unstructured / extracted-triplet settings + WikiUpdate real-world set. **DUNE** (EMNLP 2023, https://arxiv.org/abs/2311.16087 ): free-form natural-language edits ("Messi plays for Inter Miami" style); RAG beats specialised editors, neither solves it [P]. **UniEdit** (NeurIPS 2025 poster, https://neurips.cc/virtual/2025/poster/121533 ): open-domain unified benchmark [E: full contents not verified — check before registering]. **AbstainEQA** is embodied-only (CVPR 2026) — out of scope except taxonomy reuse.

## 2. 'Equal-size SOTA baseline', concretely

Open-weight ~150–600M (all runnable on one RTX 5070 Ti; 135M also on Mac CPU): **SmolLM2-135M / 360M** (HuggingFaceTB, Apache-2.0 [P, via https://huggingface.co/John200310102026/SmolLM2-135M and https://ollama.com/library/smollm2 ], trained 2T tokens [P]); **Qwen3-0.6B** (600M, Apache-2.0 [P, via https://apxml.com/models/qwen3-0-6b ], 36T tokens, 32k context); **ModernBERT-based QA reader** (~150M class; licence not verified in this pass — confirm before citing). Editing/retrieval baselines the expert demands: **ROME** (single-edit rank-one, ~4 s/edit on GPT-J [P]), **MEMIT** (mass edit, numbers above [P]), both via EasyEdit; **RAG with BM25** over the edit store (DUNE [P] and RippleEdits [P] both show retrieval beats parameter editing — this is the baseline most likely to beat us on prose benchmarks); plus **in-context editing** (RippleEdits' best scorer [P]).

## 3. Ranking (win-likelihood × Mac-CPU/5070Ti cost) and FIRST registered run

Rank: (1) **Reversal-style fictitious + TwoHopFact-curated** — highest win-likelihood (hard-coded symmetric lookup cannot show the curse; SmolLM2-135M plausibly reproduces ~chance reverse [E]) and cheapest (tiny, offline, CPU). (2) **MQuAKE-Remastered CF-3k 2-hop single-edit slice** — strong win-likelihood (notebook edits are appends, never weight overwrites) at moderate cost (needs ears mapping of real-entity prose; WebRED work shows ~half of raw sentences are negatives — expect parse loss). (3) **AbstentionBench SelfAware + KUQ slice** — medium (our abstention is structural thresholding, honest but brittle to paraphrase). (4) Full CounterFact/zsRE 10k + ROME/MEMIT on GPT-J — lowest priority: needs GPU weight-editing of a 6B model, exactly the regime our design refuses; run only as baseline-vs-baseline sanity.

FIRST registered run — "Fable-Edit-200" (seal PASSMARKS first): n=200 fixed IDs: 100 MQuAKE-Remastered CF-3k two-hop single-edit instances + 50 reversal pairs (25 fictitious NameIsDescription both directions, Berglund format) + 50 abstention items (25 SelfAware-style unknowns + 25 broken-chain). Metrics: exact match after norm (edits/reversal), abstention precision/recall + wrong-answer count on the 50. Pass marks to seal [E, proposal]: ≥85/100 edits, ≥45/50 reversal, abstention recall 50/50 with 0 wrong answers, vs SmolLM2-135M same-protocol baseline recorded but no bar. Honest failure cases to pre-register: ears rejects/mis-parses real-entity paraphrases (WebRED negatives); alias/ambiguity items; temporal (MQuAKE-T excluded); any run >30 min wall-clock is FAIL.

## What it means

A 200-item registered run built from Remastered + reversal + abstention slices can show our design's edge (append-not-overwrite edits, symmetric lookup, structural abstention) against a named equal-size baseline within Mac CPU + single-GPU limits.

## What it does not mean

No public number here is ours yet; sizes/results above are the papers', and the pass marks are proposals, not achievements — the run has not been sealed or executed, and prose-paraphrase coverage is the expected failure point.
