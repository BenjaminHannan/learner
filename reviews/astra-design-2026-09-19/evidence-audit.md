# Evidence audit — 19 September 2026

**Shown — scope.** This audit reads source, existing JSON and primary literature. It does not load tensors, import project modules, run tests/training, inspect other sessions, access remote hosts, or spend money. The only executed analysis is standard-library JSON tabulation and arithmetic. New files are confined to this review directory and `design/v3`. Source and JSON prevail over the handoff and older reports.

**Shown — reproducible evidence.** [toy-results.md](toy-results.md) is the authoritative generated toy table; [toy-runs.csv](toy-runs.csv) carries all 30 seeds and timings. [evidence.json](evidence.json) contains extracted village, handoff, address and smoke results and exact statistical calculations. [tabulate.py](tabulate.py) reads JSON only and uses exclusive creation for outputs. [input-json-manifest.json](input-json-manifest.json) records all 42 input hashes. An existing report saying a test passed is not a rerun of that test here.

## Design interpretations that outrun the evidence

**Suggested.** Explicit routing has helped multiple distinct assays, but the supplied-address, relation shortcut and handoff-mask interventions differ in inputs, privileges, training and endpoints. Their conjunction does not identify a single common cause. A pooled vector is not mathematically incapable of representing roles; it lacks separately addressable token locations. The case for token rows is an interface hypothesis with a storage and compute cost.

**Suggested.** A low no-store score in a separately trained model does not establish dependence in a trained store-using model. Removing only card rows also leaves contextual question states, slots and recurrent state. Restoration, complete path removal and sham controls are necessary before interpreting either success or failure.

**Shown — read-only limits.** This audit cannot verify saved checkpoint provenance against tensor bytes, reproduce bit-exact parity/resume, measure selector learning, estimate full-concurrency runtime, observe pending jobs, or establish causal use from a probe. All proposals remain untested. The next most valuable measurement is the already-planned **five-condition same-checkpoint path intervention with restoration**, reported seed by seed over all 30 checkpoints. It determines whether fixing lookup targets the factual path the model actually uses.
