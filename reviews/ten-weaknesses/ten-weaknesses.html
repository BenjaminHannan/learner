Premonition v1 · health check

Ten cracks in the v1 model

22 AI checkers hunted for weak spots; each suspect had to survive a skeptic trying to disprove it.

Not repeated here: the five weak spots other threads already own (bridge, loops, multi-step puzzles, held-out gap, show-your-work).

#1 · #2shown in code

The quiz itself has two flaws

Flaw 1 hits 5% of practice-exam questions and 9% of new-question ones; flaw 2 hits plan questions (13% of new ones).

Fix: flip a coin for which place is named first; mark any plan that works as right.

#3 · #4shown, re-measured

The pass lines are set too low

Brainless tricks already reach both pass lines, so “PASS” proves little. The model still wins on stories.

Fix: set each pass line 10 points above the best brainless trick (about 29% and 30%), before the next run.

#5shown in the logs

The final score is a lucky snapshot

The model keeps taking full-size learning steps right to the end, so its score wobbles by about ±2 points.

Fix: shrink the learning steps over the last 20% of training, and report the average of the last 5 checks (81.4%).

#6 · #7shown in code

Training runs with half the gauges off

Nobody can see whether the 45% on new questions rose or fell while training went on.

Fix: score new questions at every check and save the full breakdown (no change to training).

#8 · #9shown in code

The puzzle model's “don't forget” lock is never tested

One setting differs from the proven recipe, and in older tests that setting was the difference between pass and fail. Its effect on v1 is untested.

Fix: switch the setting to the proven one, and score old skills after every night, with a lock-off comparison.

#10our best guess

It stops thinking as soon as it feels sure

Harder questions get fewer rounds, not more. Part of the loops problem another thread owns.

Fix: teach “stop” only once all needed clues are fetched, as the original design planned.
