Handoff: `reviews/opus-execution-02-answer-path.md`. Local Mac CPU only. **Training time 1,196.2 s (19.9 of the
30 allowed minutes), rental cost $0.00** (total $0.00 / $30.00). `full_verdict: false` — this is a toy diagnostic,
not an Experiment-1 verdict. The toy's synthetic vocabulary is a declared diagnostic exception to the v2-tokenizer

## For Ben, in plain words

- **We reproduced the failure.** Original D was handed the correct fact card, made by its own card writer. It
  still answered only about 11% of fresh test questions (guessing gets 6%).
- **We found where it breaks: the "Think" block.**
  - With no Think step, the answer writer learns to copy the fact from the card (93% after 600 steps).
  - Put one Think pass in between and it fails (11%).
  - Think writes almost the same large vector into every row of its scratchpad, so all rows end up looking
    alike. The answer writer can then no longer tell which row is the fact card.
- **Both allowed fixes work for reading one supplied fact.**
  - *Gated Think* starts the Think block switched off and lets training turn it up.
  - *Card bypass* lets the answer writer see the card as it was before Think touched it.
  - Each scored **1024/1024** on untouched test questions, on two separate training runs (seeds).
- **But neither fix taught Think anything useful.** The gate stayed almost shut (α ≈ −0.025 and +0.001). The
  bypass simply goes around Think.
- **The repaired models copy the one card; they cannot choose.**
  - Hand them the right card plus a few wrong fact cards and accuracy falls to 43–66% (bypass) or 17–30% (gate).
  - Trained the normal way, where the model fetches cards itself, the bypass model finds the right card every
    time (100%). It still answers at chance (54/1024 test).
- **Without the card store, the reader fails too.** The version that only reads the history (D-noask), trained
  the same way, stayed at chance (8%). So in this toy the answers really come from the card.

**In one sentence:** we fixed *reading one supplied fact*. We did not yet fix *choosing among facts*, *using
facts it fetched itself*, or *combining facts*. The next bottleneck is making Think useful without it collapsing.

## 3. Interpretation, and competing explanations

1. **Established (toy, two seeds):**
   - Think's learned update writes a large row-shared vector, and the writer card's decodability degrades. Together
     these block copying a supplied card.
   - Either keeping Think's update near zero, or reading the card before Think, restores exact copying. The
     answer then depends causally on the card.
2. **Not established:**
   - That Think can learn any useful computation. The gate stayed shut and the bypass skips Think.
   - That the model can find and use its own cards.
   - That the store beats D-noask with autonomous retrieval.
   - Multi-fact combination, or anything about the village.
3. **Why choosing fails (hypothesis, supported by code and the multi-card table).**
   - The decoder's first query is computed from the `[answer]` token alone, so it is the same for every question.
     Picking the card that matches the question therefore needs question-aware rows from Think, or the decoder
     MLP's mixing.
   - Both repairs remove Think's influence on the card rows. Trained with distractors, the bypass reaches only
     623/1024 at n = 2, and its loss was still falling. So this is not a proven ceiling.
4. **Why the full curriculum fails even with supplied cards (open).** Candidates, none isolated:
   - The gold phase is only 5% (about 56 steps), while gold-only training needed 300–400.
   - Teacher/own phases always hold 2–4 cards (the choosing problem above).
   - L_lm competes for the shared reader and writer.
   - Loop-0 deep supervision runs without cards.
   - The ASK/HALT losses.
5. **The gate result is not evidence for ReZero-style benefits in general.** With α ≈ 0, the gated model is
   effectively the no-Think model. It shows that Think's update is harmful at this stage, not that gating helps
   Think learn.

## 4. Costs

Per 800 steps, as measured on a machine that was not quiet: D 71–91 s, gated 83–100 s, bypass 94–101 s.
- **Gated** adds one scalar and one elementwise blend per loop. Think's full compute is still spent.
- **Bypass** keeps one extra [Q, 16, d] copy of the inserted card rows and one concatenation per decoder call.

No FLOP-matched claim is made.

## 6. Recommendation (for Astra's review)

Do not adopt either variant as the design. Use them as diagnostic tools. The next bottleneck is **making Think do
question-dependent work without collapsing**. The smallest ladder that separates the abilities, all with supplied
cards:
1. Read one card (passed).
2. Choose the matching card among several (failed so far).
3. Combine two cards (untested).

Each rung should include a trained no-Think control and a final-loop-only supervision control, before any new
retrieval, TST or halting work.
