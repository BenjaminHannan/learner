## 1. The test

- One RTX 4090.
- `launch/e4floor.py` runs **six fresh 300-update traces in the order B, D, B, D, B, D**:
  - B = baseline, D = `defer`;
  - B3G2 3M, accum 4, batch 256, bf16 autocast, real EmbeddingGemma 2, real pool `p10-rung30-s400-a64-L`, caps_b3g2.json;
  - the same seed (400), the same rows, and the same pinned stochastic parts (gap_p 0, ans_drill 0, rounds K0 = `rounds_needed` of the seed's first batch).
- Each trace is built exactly as prof_train's own E4 builds one (`loss_curves`): a fresh `Trainer(world, args, names, batch_seed=seed)`, `pin_stochastic`, the job's real lr schedule, one float loss per update. Nothing is cached or reused between traces.
- The box script is `launch/gpu_run_5_box.sh`, `PROF_PLAN=gr5`, generated by `launch/gen_gr5_box.py` with the commit and every launch-file sha256 pinned. The setup, code, gemma, data, skills and pool-building stages are GPU-RUN-4's, unchanged. `launch/hostmon.sh` runs throughout.
- Readout: `launch/gpu_run_5_marks.py` (tests in `test_gpu_run_5_marks.py`).

## 2. Bars (the ruling, point d), all over updates 101–300 of each trace

- **AA** = mean |Δloss| of each of the **3 B–B pairs**.
- **AB** = the same for each of the **9 B–D pairs**.
- **PASS** needs both:
  - (i) the **median of the 9 AB ≤ the largest AA**; and
  - (ii) the **3 D window means do not all lie outside the B range on the same side** (not all above the largest B window mean, and not all below the smallest).
- **"It's just drift" is proved wrong** if **every AA < 0.02 AND every AB > every AA**. Then `defer` is **closed for good**. (This implies a FAIL.)
- **If any AA ≥ 0.02,** record that 0.02 is too tight for **FUTURE B3G2 sheets only**. It re-judges neither GPU-RUN-4 nor this run.
- **Incomplete run:** fewer than 6 traces in the order BDBDBD, or a trace shorter than 300 updates, cannot pass. It is recorded as **FAIL** (one rental, no re-run bids).

## 3. Consequences (the ruling, point e)

- **FAIL:** final.
- **Either way:** one rental, no re-run bids. The only change tested is E4 for `defer`.
