## What it is (one change from the GW-F loop; everything else is the A26 spec)
Same loop, model, add-on, scorer, 400 practice games a round (explore 0.10, round 1 sampled at the untrained parent's T0, later rounds at T = 1), same buffer rule (rows of earlier rounds, a uniform sample of the same size as the new rows, newest 20,000), same Adam lr 1e-3, minibatch 256, from a **fresh** add-on on each parent (T1SDR 3M, seeds 200 and 201, the A26 parents), **new practice run seeds 396 and 397** (never used), days 4(k-1)+c.
**The one change: the rows.** After a round's games are played, each game is replayed from its world seed with its executed moves (the replay must reproduce every saved view; checked). At every step, before the executed move, the world is copied once per move word (17 copies; a copy replays exactly, 2 ms) and each word is applied to its copy; a word is a **label** for that step if it makes an achievement count rise that was zero before in this game (the game's own first-unlock +1, nothing else). If a step has no label word: no row. If it has several, one of them is picked uniformly at random (seeded by the world seed and the step) and becomes the row (view, that word). Row weight: n^(-1/2) of its achievement type (n = rows of that type this round), floor largest/20, as A26. **Training on these rows: 10 epochs** (A26: 3), because there are only about 1,500 to 3,000 rows a round (at most one per achievement per game, plus ties) and A26's 90 updates a round were too few for the clean 630-row dose of GW-L (which took 2,500 updates).
Nothing about the view text, the chain or the hand-written labeller is used; the only oracle is the game's own +1 one move ahead. **It copies the world, so it is an instrument, not a method**: it cannot be used on a real game that cannot be forked. It does not label repeats (a second wood or sapling earns no first-unlock), so it teaches the last move of each link, not the walk between links and not the extra wood a pickaxe needs after the table; whether a model that gets the last moves right makes up the rest from its own play is exactly the question.
Ties: with no pickaxe and no sword and one wood, `wpick` and `wsword` are both +1, so a ready state's label is a coin toss between them while neither tool exists (then only the other).
Rounds: 7 (about 80 to 90 minutes each: play about 45, replay-and-fork about 15 on spare cores, training about 20; free CPU, started when ready and run side by side with A27 at lower priority if the cores are free).
