State 2026-09-20 morning. Lookup operator (79k TokenMemoryReasoner trained on canonical 4-token queries, Astra design/v3/17) + fixed recursive executor: seeds 1,2 perfect on all cells and 512/512 up to 10 hops / 16 people (artifacts/fable-scale-probe-20260920); seed 0 fails. v2 (more steps) did not help; v3r (lr decay 1e-3 -> 1e-4 over updates 4,000-6,000; artifacts/fable-canonical-operator-v3r-20260920) lifted seed 0 to 499/512 one-hop but it still misses c4,c5,p12-1,p12-3 — all remaining errors are relation 10 (held-out relation gets ~2.5x less canonical practice). Learned dispatcher (scripts/fable_dispatcher.py in the worktree, 15.5k params, final-answer reward only): 64/64 on 1-hop/2-hop/held-out 2-hop in 3/3 seeds, three-hop 48/0/15 of 64 because redundant calls are free (padding habits). Next registered test: call cost 0.01 (PREREGISTRATION-V2-call-cost.md).

Update 2026-09-20 ~10:00: FIRST registered all-seeds pass — dispatcher v3 (artifacts/fable-dispatcher-v3-20260920 in the worktree; trained on 1–3 hops, 6 people, final-answer reward + call cost 0.01) scores >=59/64 answers AND strict paths on every cell k=1..8, practised and held-out terminal, 16-person distinct chains, k=5 edited pairs, voluntary stop, in seeds 0,1,2. Earlier: call cost alone (1–2-hop training) passed three-hop in 2/3 seeds at 0.01 and a different 2/3 at 0.05 (rule ambiguity = luck). Operator: `balance` variant (relation-10 sampling fix + lr decay; artifacts/fable-operator-balance-20260920) passes all ten R answer cutoffs in seeds 0,1,2 (seed 0 p12-3 470/512; Astra's gold-person terminal side-mark 487 still missed there). `e0` (no supporting-line loss): seed 0 perfect, seeds 1,2 never learn — evidence loss is start-up scaffolding. Pending: marg (no intermediate labels), ablations (no recent flag / no offsets / cost 0), frozen-recipe many-seed reliability, fair transformer baseline.

Update 2026-09-20 ~10:30: dispatcher v3 ablations (3 seeds each): recent-result flag OFF -> k>=4 collapses (4–40/64); relative offsets OFF -> k>=4 collapses (~4/64); call cost OFF -> answers 64/64 on every cell k=1..8 in 3/3 seeds, only short-question paths get padded. So the decisive ingredient is TRAINING THROUGH 3 HOPS plus two SUPPLIED hints (recent-result flag, relative offsets); call cost only tidies. `balance` wave 2 (seeds 3–5) was WORSE than decay-only v3r (12-person one-hop 477–490, all relations) -> balance dropped as base; operator reliability stays 5/6 (v3r). `marg` (weakened, no hint) failed 3/3 by never starting, same as e0 seeds 1,2; start-up fixes (hintwarm / grow / grow-blind / marg-full) being built in scripts/fable_operator_startup.py.

Ben's fix list (agreed): 1 latent intermediate labels (search/sample paths, train from final answers, counterfactual shortcut tests) — biggest open problem; first cheap step = answer-only one-hop with scaled init + lr decay, since Recipe A (answer-only, unscaled init) learned ~9%. 2 reliability: find cause, freeze recipe, many seeds, report all. 3 learned continue/stop tested well beyond training length; evaluate without the 4-call cap as a diagnostic; call cost judged by accuracy not brevity. 4 ablate each supplied aid singly then jointly; list what stays supplied. 5 whole-chain success vs length (p^L); verification/recovery must be shown to correct errors. 6 encode story once + small candidate retrieval; measure misses/latency/memory. 7 fair baseline: ordinary transformer with same supervision allowed to emit steps, plus answer-only for both, matched budgets. 8 expand toy systematically (unseen names, paraphrase, distractors, new relations via definitions), size sweeps, village — only after learned three-hop is reliable.

**How to apply:** one change at a time, prereg + hash before each run, <=6 heavy CPU processes on the Mac (8 fast cores), every failure kept. See [[overnight-loop-directive]], [[token-memory-result]].
