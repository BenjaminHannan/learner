Safety rules for every fix:
- Question turns never write to the notebook.
- Never give a stored value that the question did not ask for. When in doubt, decline honestly.
- Rewrites of the user's text happen only on turns ending in "?" and only when the rewritten form is one an existing reader already handles; if the rewrite does not produce an answer, fall back to the original text's handling unchanged.
- Any inverse answer is labelled "(worked out backwards)" and never stored.
- A name counts only if it resolves to an entity already in the notebook (nb.resolve or the existing resolver); never treat a common lowercase word as a name.
