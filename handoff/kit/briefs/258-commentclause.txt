EXP 258 BRIEF: commentary clauses after a denial or correction. The director wrote this on 2026-09-22. OPUS-RULES.txt (same folder) applies in full.

Why
- Exp 252b is a registered FAIL on one junk write. After the assistant answers "Kasia's employer is Norbeck.", the user says "That's wrong, that's old news." 252's contextual-correction path reads "that's Z" as the new value and stores employer = "old news". 252b's value screen only catches contractions typed without an apostrophe, so it misses this.
- In 252b's own safety set (artifacts/claude-correct252b-20260922/dev252b.jsonl, a dev set you may read), 37 of 38 denials and corrections that end with an extra clause are not carried out.
  - The old fact stays stored.
  - In 5 of them, 252/252b now give a false reply such as "I don't have Brimwell, that's outdated as Arlo's employer, so I didn't change anything." while Brimwell IS stored. 138k asked the user to rephrase instead.
  - Exp 259 handles that false reply from the value side, in parallel. This experiment handles it from the clause side. See "Overlap" below.
- Diagnosis: after a denial, a clause like "that's old news", "that was last year" or "which is outdated" talks ABOUT the old fact. It is commentary, not a new value.

Base: 252b = scripts/claude_loop252b_agent.py with artifacts/claude-correct252b-20260922/loop252b-config.json.
- One change: a single new mixin, scripts/claude_fix258_comment.py, placed in scripts/claude_loop258_agent.py.
- Artifacts: artifacts/claude-comment258-20260922/. Ledger lines: P258.n. Never edit an existing file.

The one change
- On a turn that 252/252b already treats as a denial or a correction (use their own detection; add no new detection grammar), look for a trailing commentary clause:
  - It starts after a clause boundary: ", " " - " " — " "; " or an opening bracket.
  - It opens with that's / that is / that was / that isn't / that's not / which is / which was / this is, including the forms typed without an apostrophe ("thats").
  - It runs to the end of the turn, or to the closing bracket.
- Remove that clause before 252's parse, and never take a value from it. Then let 252b handle the shortened turn exactly as it would if the user had typed it that way. For example:
  - "That's wrong, that's old news." is handled as "That's wrong."
  - "No, it's Quarry, that's outdated." is handled as "No, it's Quarry."
  - "X doesn't work at Y (that was last year)." is handled as "X doesn't work at Y."
- Every other turn stays byte-identical, including teach turns with an appositive ("X works at Y, which is a bakery.") and questions.
- Safety:
  - No write or removal happens except through 252b's existing paths on the shortened turn.
  - Question turns never write.
  - The user's name keeps its confirm flow.
  - Inferred facts are never stored or removed.

Overlap with 259

- The two changes meet on explicit denials that carry a that-clause. Both should remove the stored fact there. A later small merge checks that they agree.
