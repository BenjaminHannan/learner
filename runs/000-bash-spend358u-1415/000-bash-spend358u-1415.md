Director read-only hourly spend read: prints rent358u-1-start's reply so far, the 358u guard's last log lines and END (if any), the vast credit number and each instance's id, label, status and $/h. Rents, stops and destroys nothing; prints no key, email or config.
```bash
Q=$HOME/premonition-watch/queue
echo "== reply"; cat "$Q/rent358u-1-start.go1.reply.md" 2>/dev/null | cut -c1-300 | head -40
echo "== guard"; for g in $(ls -d /tmp/*358u* "$TMPDIR"*358u* "$HOME"/*358u* 2>/dev/null); do echo "$g"; tail -5 "$g/log.txt" 2>/dev/null; cat "$g/END" 2>/dev/null; cat "$g/rentals.txt" 2>/dev/null; done
echo "== vast"; vastai show user --raw 2>/dev/null | grep -oE '"(credit|balance)": *-?[0-9.]+'
vastai show instances --raw 2>/dev/null | perl -MJSON::PP -e 'local $/; my $d=decode_json(<STDIN>); print "instances ", scalar(@$d), "\n"; printf "%s %s %s %.3f %s\n", $_->{id}, $_->{label}//"-", $_->{actual_status}//"-", $_->{dph_total}//0, $_->{gpu_name}//"-" for @$d'
date -u
```
