# Review of Addendum G before any hops run (2026-10-27, 18:20-18:50Z)

Five reviewers each read one part: the core loop code, the training path, the evaluation and marks, the data, and the design. A
second reviewer then tried to refute each finding by reading the code and running short CPU checks. None of them ran training or
used a GPU. Each finding below is labelled with what the check showed, then what was done.

| Finding | Check | Fix |
|---|---|---|
| Places were drawn at random per chain. "Name the most-mentioned place" scored 19-23%, rising with depth, against a plain floor of 15-20% | shown, by simulation | Every row now has 7 chains, each ending at its own place. The floor is 1/7 = 14.3% at every depth, printed in the summary |
| The number of chains (and places) fell with depth (7.1 at depth 1, 5.5 at depth 10) | shown | Fixed at 7 chains. The one remaining trend, distractor mean length (32 - d) / 6, is documented |
| "Every name is the subject of at most one line" is false for "The {b} holds the {a}." | shown, wording only | Reworded to "located item". The chain was always unique |
| The code labelled a pair-B fail without checking B3 < +1, and with B4 alone | shown | PROVED WRONG now needs B1 and B3 both below +1 |
| Several outcomes had no decision (B1 pass with B2 or B4 fail, the bands, VOID, A vs B conflicts) | shown | Eight ordered pair-B outcomes, each with its next step, plus pair-A decisions and a precedence rule. The summary prints the label and the step |
| The deep bar (5-10) needs loop counts 7-12, which no arm trains | shown | The marks read near = 5-6. Far (7-10) is reported with no mark. Depth-6 halting still reads one untrained lap; this is stated |
| No check that the loop arm is installed, so a broken hloops reads as a null | shown | V3: hloops at r = depth >= 80 on trained depths, else NOT INSTALLED (not a refutation) |
| The stop rule compared r = 12 with r = 10 (r = 11 not scored) | shown | Arms are now scored at r = 1-12 |
| PASS and fail labels lacked the one-seed and budget caveats | shown | The labels carry them. PROVED WRONG first triggers a 10,500-step run |

| The W = 0 lesion was stored but not printed | refuted as a defect (reporting choice) | Printed anyway, with |W| |
| The village smoke run tried the hops arms on village rows (found by the regression suite, not the review) | shown | --smoke without --arm runs the village arms only |
