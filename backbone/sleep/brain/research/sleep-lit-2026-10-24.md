# Sleep-B literature pass, 2026-10-24

Method note: every ID below was opened or returned by search this session; abstract-only reads are marked (abs). No Agent tool existed here, so I searched myself and had no Opus review. Labels: **shown** = the paper measured it (usually 7-8B models, big token budgets); **suggested** = my inference; **untested** = not measured in our setting. Control = LoRA row (recall 56, ARC 92.4, diary 82, updates 70). Each arm is one change on top of the LoRA control. Everything is one seed with an unknown question count, so I fixed pass marks at +5 recall points; rerun any pass with 2 more seeds.

## 1. Top 5, ranked by expected gain per GPU-hour

**1. Strategy-diverse dreams plus reversed statements (data only, same steps).**
- Change: replace paraphrase+Q&A dreams with about 7 fixed prompt types (key concepts, implications, case study, teacher-style explanation, mind map, Q&A) and add "B is A" reversed forms. Keep diary verification.
- Papers: SPA 2603.22213 (2026); Active Reading 2508.09494 (2025); Ovadia 2312.05934 (2023); Physics 3.1 2309.14316 (2023); Reversal Curse 2309.12288 (2023).
- Shown: SPA's 7 prompts beat EntiGraph and Active Reading on MultiHop-RAG with Qwen2.5-7B (86.6 vs 85.4 vs 83.3). Active Reading, SimpleWikiQA: repeat 16, paraphrase 26, synthetic Q&A 48, multi-strategy 66, and paraphrase and Q&A plateau as tokens grow. Ovadia: accuracy rose with each extra paraphrase (10 per chunk). Physics 3.1: without augmentation, 0% extraction even after Q&A tuning (from-scratch models). Untested: all of this at 2B with a few hundred dreams.
- Pass: recall >= 61, ARC >= 91.5, diary >= 80, updates >= 65, and reversed-question recall >= control + 10 (add about 20 reversed test questions).
- Wrong if: recall <= 58, or diary verification rejects over 40% of the new dream types (the formats do not survive the verifier).
- GPU link (the owner's question): dream count per fact is the natural budget knob. EntiGraph 2409.07431 is log-linear in synthetic tokens and SPA keeps improving with scale, so a stronger GPU can write and train on more strategy types per fact (suggested).

**2. Retune the LoRA control before comparing it to anything (3 short runs).**
- Change: LoRA on all linear layers (attention and MLP), rank 16, lr = 10x the best full-rank lr (5e-6 gives 5e-5). Run only if the current control is attention-only or uses a full-rank-like lr.
- Papers: LoRA Without Regret, Thinking Machines blog, 2025-09-29 (read via https://huggingface.co/docs/trl/main/en/lora_without_regret); LoRA Learns Less 2405.09673 (2024, abs).
- Shown (lab claims, not independently reproduced): all-layer LoRA beats attention-only; best LoRA lr is about 10x full fine-tuning; LoRA ties full fine-tuning on small datasets. Biderman: full fine-tuning's weight changes have 10-100x higher rank than typical LoRA.
- Pass: recall >= 61 with ARC >= 91.5 (the full-rank 5e-6 arm got 63.5/92.4).
- Wrong if: recall <= 58, so rank or capacity, not the lr, is the limit.
- Deployment note: LFM2-24B-A2B is an MoE with 40 layers, only 10 of them attention, 64 experts per block, top-4 routing (liquid.ai/blog/lfm2-24b-a2b). Attention-only LoRA there would touch very little; test MLP/expert targets on the target model early (untested).

**3. Two-hop "bridge dreams".**
- Change: for each pair of facts sharing an entity (A->B, B->C), add (a) one dream passage with both facts adjacent, and (b) answers that write the bridge before the final answer ("Alice's dentist is Dr. Lee, who works at Oak Clinic, so Oak Clinic"). Hold out some pairs from training.
- Papers: Lessons from Two-Hop Latent Reasoning 2411.16353 (2024, v4 2025); Identity Bridge 2509.24653 (2025); Physics 3.2 2309.14402 (2023, abs); Distilling System 2 into System 1 2407.06023 (2024, abs).
- Shown: separately learned synthetic facts give chance-level two-hop without chain of thought (Llama 3 8B, Qwen 2.5 7B, GPT-4o), even with two-hop chain-of-thought examples in training. Facts in the same document or prompt gave non-zero accuracy. One natural plus one synthetic fact gave about 20%. Identity Bridge: supervising the bridge token lets small transformers compose unseen pairs. Physics 3.2: composition needs chain of thought in training and testing. Untested: that our REM chains differ from these.
- Pass: held-out-pair two-hop >= 40% when the chain is written, one-hop recall >= 55.
- Wrong if: held-out pairs stay <= 25 while trained pairs rise, which means memorised pairs rather than composition.

**4. Context-distillation for the closed-book copy of the open-book Q&As.**
- Change: teacher = same model with diary turns in the prompt, student = no diary. Add a top-k logit KL to the teacher's distribution on the verified answer tokens, in place of or beside hard labels. This is off-policy (no sampling), so it costs about one extra forward pass.
- Papers: SDFT 2601.19897 (2026); Cartridges 2506.06266 (2025, ICLR 2026); Limits of on-policy self-distillation 2607.01763 (2026, abs).
- Shown: Qwen2.5-7B, full fine-tuning, new-facts corpus: SFT 80/95/80 (strict/lenient/indirect) vs SDFT 89/100/98, oracle RAG 91/100/100; about 2.5x FLOPs. Cartridges: self-study with context distillation matches in-context learning, and plain next-token training does not.
- Risk, shown: a 3B teacher gave no gain over SFT, and on-policy self-distillation can forget or collapse in continual use. Hence the off-policy form and the morning gate.
- Precondition (free): check the base model's accuracy with the diary in context. If it is below about 85% the teacher is the bottleneck.
- Pass: recall >= 61, diary >= 80, ARC >= 91.5.
- Wrong if: recall gain < 3, or ARC falls below 90.

**5. Contrast-based weight selection for the sparse arm.**
- Change: rank weights (or MLP rows) by |g_night| / (mean |g_generic| + eps) instead of summed gradient size alone. Same 1.2% budget, same lr. Needs about 50 generic-text backward passes once. On the MoE, the analogue is experts the night's tokens use far more than generic text does (untested).
- Paper: Sparse Memory Finetuning 2510.15103 (2025); Memory Layers at Scale 2412.09764 (2024, abs).
- Shown: 1.3B model with a memory layer pretrained in. Slots chosen by TF-IDF against background usage. NaturalQuestions F1 fell 89% (full fine-tuning), 71% (LoRA), 11% (sparse). It used SGD, not AdamW. Untested: dense models.
- Pass: recall >= 58 (the current sparse arm got 53.5), updates >= 60, ARC >= 92, diary >= 80.
- Wrong if: recall stays within 3 of 53.5.

## 2. Notes on papers read
- EntiGraph 2409.07431 (2024): entity-pair synthetic text, 265 books, Llama 3 8B; recovers about 80% of the open-book gain; log-linear in tokens. Shown.
- Physics 3.1 2309.14316 (2023, ICML 2024): knowledge must be varied (paraphrase, shuffling, translation) to be extractable. Shown, synthetic bios.
- Ovadia 2312.05934 (2023, EMNLP 2024): Mistral current events: base 0.481, RAG 0.875, fine-tune 0.504, fine-tune on 10 paraphrases 0.588, fine-tune + RAG 0.830. Shown.
- SEAL 2506.10943 (2025): the model writes its own "implications" (Qwen2.5-7B; 32.7 base, 46.3 GPT-4.1 data, 47.0 SEAL, LoRA, one passage). Earlier tasks decay over sequential edits. Shown.
- Pre-instruction-tuning 2402.12847 (2024, abs): Q&A training before document training beat the usual order by 17.8%. Untested for us; a free ordering test.
- Gekhman 2405.05904 (2024); Pletenev 2502.14502 (2025): see section 3.
- LISA 2403.17919 (2024, abs): random layer freezing matches LoRA on instruction tuning, not knowledge; weak support for rotating regions. SSR 2403.01244 (2024, abs): self-written rehearsal data; compare with the KL guard.
- AlphaEdit 2410.02355 (2024, abs): project updates onto the null space of preserved knowledge. Candidate to replace the KL guard (untested).
- RAFT 2403.10131 (2024, abs): train with oracle plus distractor documents. Our open-book prompts have no distractors (suggested).
- Sleep: Tadros 2022 (Nature Communications, doi 10.1038/s41467-022-34938-7) and Wake-Sleep Consolidated Learning 2401.08623 (abs) use image classifiers. "Language Models Need Sleep" 2606.03979 (2026, abs) reports no numbers I could read. 2605.26099 (SSM fast weights) and SleepGate 2603.14517 (a 793K-parameter toy) are architecture papers.

## 3. Warnings against the current design
- **Noise:** one seed. A 5-point gap is probably within noise (suggested).
- **New facts hurt:** Gekhman 2405.05904 shows new facts are learned slowly and then raise hallucination. Pletenev (rank-1 LoRA, Llama-3.1-8B, lr 1e-3, 10 epochs): 500 new facts ~100% learned. At 3,000 facts with known-fact anchors only 48% were learned, and MMLU fell 0.677 to 0.554 (to 0.441 with paraphrases). Extreme settings, but the direction applies. Cheap guard: mix in facts the base already knows (suggested).
- **Open-book half:** no paper found that tests whether open-book rehearsal hurts closed-book recall. Mechanism (answer copyable from the prompt gives little gradient on the fact) is untested. Ovadia shows fine-tune + RAG can be worse than RAG alone (0.810 vs 0.875), which supports open-book training. Ablate the open-book share (0/25/50%) if recall stalls.
- **Sparse arm:** the paper's gain is for a model pretrained with memory layers; dense transfer is untested.
- **Sleep evidence:** none of the sleep papers consolidate facts into LLM weights. The design rests on knowledge-injection papers.
- **Twisted dreams:** SPA reports diversity collapse under RL-tuned generators. Check the rejection rate before trusting strange dreams.
- **Two-hop:** failure appears even in frontier models after fine-tuning on separate facts, so 0-22% is expected. Test chain-of-thought readout first.
- **4-bit:** all papers train in bf16. LoRA on 4-bit weights of an MoE is untested.

## 4. Plain-language summary for Ben
1. Learning one fact many different ways works better than rehearsing one wording, so write many kinds of dreams per fact.
2. A stronger GPU can write and learn from more dreams, so the night can scale with the machine.
3. Our add-on may just be set up badly; a quick retune could match the best big-change result.
4. Two-step questions fail because the model learns facts separately. Teach pairs together, and let it write out the middle step.
5. Nobody has shown sleep works on a chatbot's facts yet, so every idea here stays a test with a pass mark.
