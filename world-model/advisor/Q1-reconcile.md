# Advisor question: reconcile two world-model grounding designs into ONE first test

Context (shown, code read): a recurrent "board" model (64 rows x 256, first 24 = slow rows) has an imagine mode that runs the shared trunk on (board rows + one action row + mode/clock embeddings), attending to read-only sensory context rows. Outputs: z_pred = mean(slow rows of CURRENT board) + linear_head(action-row output); next_rows = rows + out_proj(trunk out). Loss today: MSE(z_pred, detached real next slow-row mean). Nothing trains next_rows, yet a multi-step rollout would feed next_rows back in. Planning runs imagine with all weights/context/start board detached. Owner rule: "world model trains only on real observed transitions, never on its own imagined rollouts"; policy may dream short rollouts with frozen WM starting from real states. Environment: a small Crafter-like survival game (64x64 RGB, 17 actions). Laptop-first, ~30 min, toy shape (~3M active params).

Design A: one affine decoder from mean slow rows of next_rows -> real next frame pooled to 16x16 RGB. Train 1-step only (k=1), 4,096 train transitions (32 seeds), 2,048 held-out (16 seeds), 512 Adam steps. Score k=1,3,5 open-loop rollouts with logged actions vs "show frame t unchanged": R_k <= 0.80/0.90/0.95; action-shuffle gap >= 0.10 (k=1), >= 0.05 (k=5) in >= 12/16 worlds; predicted one-step variance within action group 0.25-2x real. Free check first: move-vs-noop pixel MSE exceeds noop-vs-noop by 1e-4 on >= 8/24 prefixes.

Design B: small zero-init attention head reading only the imagined board predicts the CHANGE in the next frame's frozen image-encoder rows; trained unrolled k=1..5, inputs at k>1 are imagined boards, every target is a real frame. 50k train / 10k held-out transitions. Marks: E_k <= 0.80/0.85/0.90 x best of (nothing-changes, best fixed blend with mean frame); shuffle error >= 1.25x on moved windows; predicted-change std >= 0.2x real; >= 8 PCs for 90% variance. Free check: encoder sensitivity (moved-step feature change / random same-episode distance) < 0.1 -> switch to 32x32 pixels.

My draft reconcile: train k=1 only (strict rule reading, so no rule question), target chosen by a combined free check (pixel move-vs-noop AND encoder sensitivity; pixels 16x16 if encoder blind), head reads next_rows (so the fed-back board gets trained), baseline = better of copy and best blend, marks = B's k-marks + A's shuffle and variance checks + B's PC check, data 20k/5k transitions. If PARTIAL (k=1 ok, k=3/5 drift), the next step "unrolled training with real targets" is put to the owner as a rule-interpretation decision.

Questions (answer in <= 400 words): 1) Any flaw in the reconcile? 2) Is 20k/5k and ~1,500 steps the right size for a 30-min laptop run at ~3M active? 3) Fix exact numeric marks for (a) k=1/3/5, (b) shuffle, (c) collapse, and PASS/PARTIAL/WRONG odds. 4) The single result that proves the plan wrong.
