**1. Train for current-frame reconstruction, not change prediction.** Start unpinned. Encode each 4×4 RGB patch with a full-column-rank linear map plus a position embedding; use a fixed training-set RMS scale so patch brightness survives. Freeze the trunk but backpropagate through it to the reader. Sweep 1, 2, 4, and 8 ticks with the same context; select on validation worlds, using realistic frame histories.

Decode only the final updated rows. Center and scale each row coordinate using training statistics: a 1% signal needn’t be a low-information signal if the other 99% is a stable offset. Start with tuned ridge on flattened rows; keep it as a skip connection when adding a shallow residual MLP. Train on current-frame RGB MSE with AdamW (starting LRs: reader \(10^{-4}\), decoder \(3\times10^{-4}\)). If small sprites are neglected, average whole-frame and changed-pixel MSE equally; use the change mask only in the loss. As a separate mailbox experiment, pin 16 fast rows and decode **only the other 48**, including for ridge.

**2. Score on unseen worlds.** Report summed squared error divided by that of the training-set mean frame, both overall and restricted to pixels that changed since the previous frame (predefine the change threshold). Illustrative “sharp” targets, not universal cutoffs: **≤0.10 overall, ≤0.25 on changed pixels**, and beat previous-frame copy on changed pixels. Report uncertainty across worlds.

Allow no decoder access to context, pinned rows, previous frames, or per-example normalization statistics from the image. Hold history fixed and swap the current frame: reconstruction should follow the swap. Blank the current read to measure history-only performance. For retention rather than immediate transfer, also test one extra context-free tick after clearing any mailbox.

**3. Diagnose before blaming the trunk.** Near-lossless decoding directly from reader tokens, but poor ridge *and* nonlinear decoding from legal rows across tick counts, implicates trunk transfer; it does not prove a limit. For a fixed harness, proof would require irrecoverable ambiguity—for example, identical legal states for distinct frames often enough that even the optimal decoder exceeds the error target. That would establish a limit for that configuration, not every possible reader.
