Sleep test T3

Should the newest night count more?

The model sleeps three nights. Each night it can replay puzzles from every night so far. Do the newest deserve more weight?

The catch

Every night has the same two kinds

So an old night's puzzles look just like the newest. We added a memory so the weights are the only change.

Runs

4 seeds, 3 tries each

Same start, same puzzles, same random numbers. Only the weights change.

How we judge

The gain must reach 24 of 400

That is twice the usual night-to-night wobble of about 12. Sums have only 12 to 24 left to gain, so they only need to not get worse.

What would prove it wrong

No seed gains more than 6

We guess that is 60 percent likely, because old and new nights look alike. Pass: about 8 percent.

What happens next

Needs the PC graphics card

Four jobs, one per seed, held for the Director. If it fails, the next idea is a different skill each night.
