Scope: actual checkpoint-specific sparse attention transformer plus qualified dense control. Source seeds0/1; new actual source-upcycled checkpoints from Peirce's attention-ready manifest. Separate awake gate accepts only a separately frozen own manifest with BOTH seed/arm checkpoint hashes and phase=awake. No source result transfers to awake. Do not change existing sealed attention code or run its bundled sleep.

Only symbolic generator inputs and code-checked targets; no model-written prose/templates. No final questions/panels or old panel rescoring. Use input/label hashes frozen BEFORE all trajectory collection or scoring. New draws exclude all inputs in reconstructed historical DEVELOPMENT and source/day pools, and each other; mazes exclude D4 orbits. Historical data are reconstructed for key exclusion only, never scored/read from final files.

Budget per source seed/arm: frozen core, cap48, batch8, one CPU thread fp32. Source families sums4/grids5 (32 TRAIN,16 TRAIN-calibration,16 TRAIN-noise,24 fresh DEV each). Awake additionally mazes9/11 DEV24 each with32 maze9 TRAIN/16 cal/16 noise. State-only D256 pooled ->32 hidden->1 head,8257 parameters. No reasoner or sleep optimizer. Max60min per phase, $0, serial Mac watcher job. Targets: persistent exact correctness from every TRAIN continuation through48; sums use the code arithmetic checker (leading zero values accepted); grids/unique mazes use canonical slot equality. Calibration uses only TRAIN-cal inputs/labels: smallest threshold in [.5,.75,.9,.95,.99,1] with zero persistent-label unsafe first stops; threshold1 means no learned stop. Every fit head is frozen before DEV.

Measured noise provenance: two fixed head-fit replicas evaluated on TRAIN-noise, raw per-row correctness/depth/stop and executed work stored. Primary replica0 fixed before any scores; replica1 is never selected. Accuracy gain is unjudged. Same-head no-regression against higher-of-controls is a strict engineering requirement. Work gain bar=max(.01, 2*abs(rep0 work-rep1 work)/(N_noise*48)+1/(N_noise*48)); measured bar is persisted BEFORE any DEV score and is strictly above measured calibration variation. No historical noise estimate is transferred; no scientific effect/promotion claim.

DEV controls per seed/arm/kind: primary state-head learned-only, SAME HEAD/budget plus three masked stable predictions, inherited original halt + full-grid three-step guard, fixed16 and fixed48. Never infer speed from rounds. Count actual physical active batches and partial linear work including read/controller separately. ALL learned and same-head guarded DEV batches require exact selected latent/masks/predictions/rounds/stops parity with uncompacted execution. Core and head hashes frozen. Old learned source guard is retained as original comparator, not silently renamed learned-only.

Per-arm/per-kind local diagnostic eligibility: primary exact >=max(same-head guarded,inherited guarded,fixed16,fixed48); at least one primary learned stop on a correctly answered row; physical row-round saving vs same-head guarded >the prewritten work-noise bar. Both source seeds must meet all conditions. This deliberately does not allow a head that merely avoids all stops to pass. Awake mazes additionally require fixed16 or48 solves >=1 DEV item in each seed, otherwise learned-stop readiness for new skill is NOT SHOWN. Failing dense rows remain reported and don't rescue candidate failures.

`local_gate_eligible` is a diagnostic condition only. `accepted_stop_ready=false`, every stage proof NOT SHOWN, until an independent Sol recount from raw records and THESE presealed marks only accepts the exact phase/checkpoint/code/input/head hashes. No scientific promotion, English claim, sleep benefit, F_eq/F_few or same-size superiority. Sleep is held if source/awake gate is missing, mixed, invalid or unaccepted. A clean source gate allows only next awake stage; actual sleep additionally needs accepted awake gate and idle/interrupt/retention checks.

Exclusive output-directory reservation blocks repeated DEV scores after interruption; no resume/retrain/re-score. Full input freeze happens before trajectory collection, noise bar freeze before DEV. Post-awake new manifest must precede any awake fitting/scoring; source manifest/hash cannot be substituted.
