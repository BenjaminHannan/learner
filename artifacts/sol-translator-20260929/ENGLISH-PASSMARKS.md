# English translator: fixed fresh-dev marks

This is a separate experiment from the sealed symbolic plan. Grammatical conversation is required for the 7 AM Sep30 New York PoC. A symbolic token demo cannot satisfy it.

Frozen qualified source/SleepMoE -> shared stop adapter -> final state + shape/slots -> fresh bottleneck prefix adapter -> frozen local causal English decoder. No raw question, notes, labels, trajectory, answer-head predictions or text frames enter the decoder. No teacher forcing even during training: target tokens enter cross-entropy only; rollout context contains constant BOS and self-generated tokens. All reference texts must match byte spans in verified human-origin source documents. Existing GLM/Luna/Claude/Sol text is inadmissible. A frozen pretrained component is permitted with explicit model/revision/weight hashes and honest mixed/unknown pretraining-origin disclosure; this does not authorize model-generated adaptation data.

Before a scored run: seal the human train/dev manifest and source references, all checkpoint hashes, exact shared adapter policy and the local frozen LM provenance. Split by source document and content/fact identity. No benchmark or official blind files are admitted. Missing weights, human-origin state/text pairs, learned input translator or core adapter = WAITING, never a substituted template demo.

Four runs (two source seeds × two prefix seeds); 512 training records, 100 fresh dev records per source seed. All six state arms receive identical target-only supervision, budgets and shape/slot metadata. Train the reasoner zero steps; freeze the LM; at most 10% adapter/source parameters; record active/stored LM and reasoner weights, forward/backward calls, examples, generated tokens, time, memory, disk, source hashes. These trained adapters need not be the thin symbolic decoder’s weights.

Per run on 100 dev items: >=90 grammatical complete sentences and >=90 answers faithfully expressing ONLY content verified in the final reasoner state. Grammar and content are scored separately by a human from raw outputs and the presealed rubric; a generic fluent sentence gets no content credit. >=90% content retention on the source-head-correct subset; reasoner correct on >=80 items. Strongest no-state / embedding-only / untrained / shuffled-state control <=50 content-correct and loop exceeds it by >=30. Loop-credit additionally needs loop-minus-plain >=10 content-correct in every run. Maximum prefix-seed spread <=4 counts in each arm; training-minus-dev fidelity <=20 points. Control success means leakage/not-shown, even if grammar is excellent. Same-state outputs must be invariant under outside prompt/label/notes mutations; reasoner and LM parameters must stay bit-identical.

No decoder run-to-run noise exists: the bars are exploratory, not claimed above measured noise. All passing gates -> DEV-SUPPORT-NOISE-UNCALIBRATED, never SHOWN/promoted. A non-win in only some seeds -> NOT-SHOWN. Only when all four valid runs miss retention -> DECODER-NOT-SHOWN-ALL-SEEDS. No architecture rejection is inferred. No self-judged generated training text.

Self-check: (1) insufficient-noise caveat explicit, zero repeats; (2) all-seeds rejection reading; (3) strongest causal controls + practised plain comparator; (4) positive loop-minus-plain required separately; (5) F_few/F_eq not applicable, no reasoner adaptation; (6) no sleep experiment here. Real notebook and real sleep remain core-worker dependencies for the joined deadline PoC.
