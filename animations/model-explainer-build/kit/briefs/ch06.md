# ch06 — The stop switch (kicker "Part 6 of 14", title "Deciding when it is done", accent stop)
Target: 9-12 scenes, 200-250 s. Purple stop switch. Everything here is BUILT BUT NEVER RUN: amber, said clearly and early.

Must cover:
1. Where we are; the problem: a fixed number of rounds is a hand-set rule; easy questions waste rounds, hard ones may need more. Real evidence from G1: fewer rounds = worse (ch09 numbers: 0 rounds 0.66, 1 round 20.00, 2 rounds 29.30, 12 rounds 73.01 on pooled-5, 3M seed 400) and on one older probe, 16 rounds cost 1.2-1.9 points against fewer (INPUT-UNITS-2026-10-07 line 31). So both too few and too many hurt.
2. The learned stop (H1): after each round a tiny head looks at the thinker's notes and decides "done?"; width+1 numbers: 257 at width 256, 513 at 512; at least 1 round, at most 32 (safety cap). One stop for the whole answer (not one per call). Explain "a tiny share of the model".
3. How it is trained: label "settled" = stop once no later round would be right; the "settled" fix (audit B13-2): the stop loss now counts only in batches that ran all 32 rounds (about 1 in 4), because a row right only after round n looked "settled" at every earlier round and taught the head to stop early. The project owner allowed the fix before any run. Phrase simply; source big-run/PLAN.md amendment 1:25 PM ET. Also: it learns to stop on questions it cannot solve, not only when it is sure.
4. How it will be judged (pass marks written before the run): easy questions use at most half the rounds of hard ones (1-step vs 12-step); fails if it never stops early; practised within 1 round, longer chains within 2 of always-32 (big-run/PLAN.md scorecard row 5; B3-4 in PLAN sec. 5). Show as a target, with dashed empty bars, NOT a result.
5. Calls at any round (B3 group 1) interacts with stopping: the thinker may think for a few rounds between calls.
6. The risk, stated plainly (suggested): the "settled" label only looks over rounds the row actually ran, so a stop that fires early is never shown a later right answer; the first run reports early-stop share and the answers on those rows.
7. Fast and slow thinking (fast-slow-2026-10-08.md): "fast/slow" is one looped thinker that stops when it is settled; no separate fast and slow models.
8. Status: built, never run; first run is B3 group 1 at 3M after the G1 test finishes; if the stop fails, it cannot be removed by a switch (only by running the parent model T1SDR).
9. Recap.
