glim-eyes-mmproj-f16.gguf (Glim's eyes) contains:
- SigLIP2 base patch16-256 vision tower (google/siglip2-base-patch16-256), Apache License 2.0, https://www.apache.org/licenses/LICENSE-2.0
- Glim's vision projector (premonition-projectors), code and weights Apache License 2.0. It was trained on
  lmms-lab/LLaVA-ReCap-558K captions (LAION / CC3M / SBU images), data released for research use:
  treat the vision projector as research-use.
The brain, Nanbeige4.2-3B (bartowski/Nanbeige_Nanbeige4.2-3B-GGUF), is downloaded on first run and is Apache License 2.0.
llama-server.exe (llama.cpp) is MIT licensed, see ..\llama\LICENSE.
