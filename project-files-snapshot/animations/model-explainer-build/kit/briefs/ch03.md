# ch03 — The reader (kicker "Part 3 of 14", title "The reader: giving every letter a meaning", accent reader)
Target: 11-14 scenes, 240-300 s.

Purpose: explain exactly what the reader does, what is borrowed and what is ours, and the evidence for it.
Must cover:
1. Where we are (map, reader highlighted). Reader = EmbeddingGemma 2 text part: 271,002,624 numbers, borrowed, frozen. It reads the question ONCE; each letter gets the 768-number state of the Gemma token it sits in. (FINISHED sec. 2 Reader row.)
2. Tokens vs letters: Gemma cuts text into word pieces (tokens); our thinker works on letters. Real numbers: 3.1 letters per token on the skill questions and 4.3 on web text (TOKENS-EXPERIMENT sec. 1, shown by measurement 10-09). Show a short example cut into tokens ONLY if you can compute it from a source; otherwise label it an illustration.
3. The adapter: one linear layer from Gemma's 768 numbers to the thinker's width: 196,864 numbers at width 256, 393,728 at 512 (learned). Explain "a converter plug".
4. The letter window: two small learned layers; each letter sees 4 letters left and 4 right on top of Gemma's meaning; about 0.7M at width 256, about 2.6M at 512; kept (project owner's call). Why it matters: without it the cipher puzzles collapse (cipher_map 100% down to 2.5-10%; RESULTS-EG2 in custom-io). Show real cipher_map numbers only if you find them in the file.
5. Position table: learned, 2,000 rows in B3 (reads up to 2,000 letters); G1 keeps 280. Real numbers: in a 4,000-question sample of the bAbI test set, 32% are longer than 280 letters, 1% longer than 2,000 (FINISHED sec. 7 Q2).
6. The number finder: today a plain pattern (hand-written regex) finds the numbers in the question (slots: 16 in T1SDR, 91 in G1, 240 in B3 caps); a learned replacement (N1) is planned in group 2. Show it with the brown "hand-written" chip. Note it records positions only, no values.
7. Calculator replies are read by the letter window only, not by Gemma (suggested reasoning, labelled so).

Gemma readers also answer some questions with zero rounds (EGE 18.09 in-distribution on seed 200 against 1.40 for B2V; cause not settled). Show as tested-with-caveats (green + amber).
9. The open question: tokens instead of letters (test TK, built never run; ch12 covers it); one sentence only here.
