## The change (one: the practice joins are made by joining two whole help formulas)

A domain-free whole-formula join ring, built from the help page and the tool's verdict only:
- **whole piece** of a help example: its longest value slot under R1's test (replacing the piece by `1` gives a prompt
  the tool computes a value for); ties go to the first. The build prints each help example's whole piece.
- **join**: host = a help example (ring 1, clean grid); its whole piece P is replaced by P joined with the whole piece Q
  of a help example (any, the host's own included) by a one-character symbol s of the help page, in one of the six
  generic forms of L4 (`P s Q`, `Q s P`, `(P) s (Q)`, `(Q) s (P)`, `P Q s`, `Q P s`, bracket forms only because the
  help page uses round brackets), with an empty or a single-space separator.
- **balanced join kinds** (as L4 R1): the first 20,000 tries find the (form, symbol) kinds the tool accepts; the ring
  then fills an equal quota per accepted kind. Kept when the tool runs it within the caps (full accept) and its digit
  shape is new.
Nothing in it names a spreadsheet function, an operator or a layout: it is the plainest way to put two things the help
page shows next to each other, and the same rules run on RPN (postfix forms) or code.

Training rows: as L8 (one difference: the joined rows are drafted only from this ring instead of the substitution
ring): 6,000 joined rows through the mode's own A10 edits and caps, 6,000 not-joined rows from rings 1-3, each trained
on the tool's working. Excluded: the probe file and the L5 eval rows (the domain-mode panels are unreadable in this
container, so not excluded; L9 is never scored on them). Before training the build reports the ring, the accepted join
kinds, the joined rows' top layouts, arrangement and fn-op-fn shares (as L8).

Arms and scoring exactly as L8: LA64 (rank 64, alpha 128, lr 1e-3, base frozen) and LB (every weight, lr 1e-4,
reference), parent T1SDR s200, 4,000 updates, batch 64, no replay; cells `l8` (every probe cell, F4-plus / F4-times,
S5/S/HP/HO/HPO, fit) at 0/500/1,000/2,000/4,000.
