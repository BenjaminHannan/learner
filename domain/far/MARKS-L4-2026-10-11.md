## The one change (from L2): the swap tool also joins

Same as L2 (parent s200, rank-8 add-on LA and every-weight LB, 4,000 updates, batch 64, no replay, 6,000 joined + 6,000
other rows from the practice maker, scored kinds, seeds 93601 / 93602), except the practice maker's swap tool has one more
domain-free step, **join**, applied after rings 2-3 are built:
- symbols = every one-character token of the help prompts that is not a letter, digit, space or bracket;
- a join replaces one well-formed piece P of a ring 1-3 example with one of: `P s Q`, `Q s P`, `(P) s (Q)`, `(Q) s (P)`
  (bracket forms only when the help page uses round brackets), `P Q s`, `Q P s` (postfix), each with an empty or a single
  space separator, where Q is a well-formed piece of any help example and s a symbol; all choices random from the run's
  stream;
- kept when the domain's tool runs it within the model's caps and its digit shape is new, until the join ring holds
  widen_ring_max (3,000) examples or 1,000 x 3,000 tries are spent;
- the join ring is ring 4; practice picks rings 1-4 evenly.
The tool knows text only (pieces, symbols, brackets); it is the same for every domain.

Disclosed: designed after seeing L3 and the probe generator's arrangements. A mode run of this change would be scored on
a fresh panel draw (v4).

## Revision R1 (Sun Oct 11, 11:50 AM ET, after the build, before any L4 training)

The first build of the join step (as written above) made the test's bracketed arrangement in only 34 of 6,000 joined
rows (0.6%): random pieces and random symbols rarely give a formula the tool runs (2,263 kept of 3,000,000 tries). That
would make J2 fail for a reason already visible before training, so the join step is revised (still domain-free, still
text plus the tool's verdict), and the build is redone into a new file:
- **value pieces**: a well-formed piece P of an example is a value slot when the example with P replaced by `1` still
  runs (the domain's tool, within caps). The join's P is a value slot of the ring 1-3 example being joined; its Q is a
  value piece of any help example (a value slot there).
- **balanced join kinds**: a join kind is a (form, symbol) pair. A short probe (the first 20,000 tries) finds the join
  kinds that the tool ever accepts; the ring then fills an equal quota per accepted join kind (widen_ring_max divided by
  their number), tries capped as before.
Marks, arms, data sizes and scoring are unchanged. The arrangement shares of the new build are reported before training.

Rebuild under R1 (shown, before training): ring 4 holds 19 accepted join kinds x 157 (forms with + - * /; postfix only
P Q s with + - *). Training file `train-rows-l4r1.jsonl` (sha256 d70345da...ec2). Joined rows: plus 45.9%, bracket-times
1.1% (65 rows, mostly brackets around numbers), other 53.0%; only 10.9% of joined rows come from ring 4, because ring-4
