## The change (one: the join step is replaced by a substitution step)

A domain-free substitution ring, built from the help page and the tool's verdict only:
- **value slot** (as L4 R1): a well-formed piece of an example such that the example with that piece replaced by `1`
  still runs. **value pieces**: the text of every value slot of every help example.
- **substitution**: in an example, replace one value slot by one value piece, either bare or wrapped in the help page's
  round brackets (wrap with chance 1/2, only if the help page uses round brackets). Keep the result when the tool runs
  it within the caps and its digit shape is new.
- **recursive**: the ring starts from the help examples (ring 1, clean grids) and every kept result can be a host
  again, up to 3 substitutions deep.
- **balanced layouts**: an example's layout is its whole text with every letter-or-digit token written as `x`
  (ring 1 hosts share one grid, and a substitution into the grid only changes digits, so in practice layouts differ
  only in the formula). A probe (the first 20,000 tries) finds the layouts the tool
  accepts; the ring then fills an equal quota per accepted layout (the ring's size divided by their number).
Nothing in it names a spreadsheet function, an operator or a layout; the same rules run on any text domain with brackets
(RPN has none, so it gets bare substitutions only).

Training rows (the L2/L4 recipe, one difference): 6,000 joined rows (two kinds in one formula, by the coverage parser)
drafted only from the substitution ring through the mode's own A10 edits and caps, plus 6,000 not-joined rows from
rings 1-3 as in L2/L4; each row trained on the tool's working. Excluded: the probe file and the L5 eval rows. The
domain-mode panels are on /mnt/project-files, which this container cannot read, so they are not excluded and L8 is
never scored on them. Before training, the build reports: ring size, accepted layouts, the share of joined rows per
layout (top 15), per arrangement (`K+J`-like plus, bracket-times, other), the share where both sides of a top-level
`+` or `*` are function calls, and substitution depth.

Arms (parent T1SDR s200, 4,000 updates, batch 64, no replay, same seed and order rules as L5-L7):
- **LA64**: the add-on at rank 64, alpha 128, lr 1e-3, base frozen (L6's add-on).
- **LB**: every weight, lr 1e-4 (reference only: tells whether a miss is the data or the add-on).
Scored at 0/500/1,000/2,000/4,000 on every probe cell (F0-F5, LEN), F4 split into its `K+J` and `(K)*(J)` halves,
the L5 eval cells (S5, S, HP, HO, HPO; an outside check, those layouts are hand-made) and fit (420 own joined rows).

## Revision R1 (Mon Oct 12, 7:20 AM ET, after the first build, before any L8 training)

The first build (shown) made 0 joined rows in 20M draws, so nothing was written. Cause: a value slot was tested with the
mode's full accept, which needs at least one calculator step, so replacing a whole call such as `SUM(A1:A3)` by `1`
(leaving `=1`, no steps) never counted, and the 36 value pieces were only digits, grid fragments, cell names, `A1+B2`
and `B2*2`. No substitution could put a second function call in a formula (the same flaw made L4's joins mostly
brackets around numbers). Second, grid fragments are value pieces, so grids changed with every substitution and the
layout quota spread over 918 layouts (top one 11 examples). Revised, still domain-free (text plus the tool's verdict):
- **value slot test**: replacing the piece by `1` gives a prompt the tool computes a value for (not `?`); zero steps
  and the caps are allowed here. Kept examples still need the full accept (at least one step, within the caps).
- **layout**: as before, then every run of `x` separated only by spaces is written as one `x` (a space-separated list
  counts once, whatever its length).
Also (shown, a judgement call in the build): not-joined rows drafted from rings 1-3 that the coverage parser calls
joined (699 in the first build) are dropped rather than moved, since joined rows come only from the substitution ring.
Marks, arms, data sizes and scoring are unchanged. The build's shares are reported here before training.
